# ADR-0004: Контейнеризація серверних компонентів і локальне середовище на Docker Compose

- **Статус:** Accepted
- **Дата:** 2026-11-26
- **Лабораторна:** №2

## Контекст

Діаграму контейнерів C4 (лаба №1) потрібно перенести у відтворюване середовище, яке однаково запускається на будь-якому комп'ютері однією командою і максимально близьке до продакшену (Kubernetes). Серверні сервіси написані на Kotlin / JVM і збираються Gradle, а мобільний клієнт (`:composeApp`) потребує Android SDK, якого немає в серверних образах.

Під час роботи з'ясувалося, що офіційні образи `minio/minio` більше не публікуються в Docker Hub, тож для локального S3-сховища потрібна інша реалізація.

## Рішення

1. **Multi-stage Dockerfile** для `api` та `orchestrator`:
   - етап `builder` (`eclipse-temurin:21-jdk`) збирає сервіс Gradle wrapper-ом; build-скрипти копіюються окремо від коду, тому шар із залежностями кешується; Gradle-кеш винесено в BuildKit cache mount;
   - у `orchestrator` unit-тести виконуються під час збірки: якщо тести падають, образ не збирається;
   - етап `runtime` (`eclipse-temurin:21-jre-alpine`) містить лише JRE і результат `installDist`, процес працює від користувача `labrunner` (uid 10001);
   - змінна `LABRUNNER_SERVER_ONLY=true` виключає мобільний модуль із Gradle-збірки в контейнері.
2. **Docker Compose** описує 5 сервісів: `db` (PostgreSQL 16), `redis` (Redis 7, AOF), `storage` (RustFS 1.0.7 — S3-сумісне сховище), `api`, `orchestrator`.
   - Дві мережі: `public-net` (лише `api`, єдиний опублікований порт 8080) і `backend-net` з `internal: true` (без виходу назовні, без опублікованих портів).
   - Іменовані томи `pg_data`, `redis_data`, `storage_data`.
   - Порядок запуску через `healthcheck` + `depends_on: condition: service_healthy`; `orchestrator` чекає на здоровий `api`, бо саме API застосовує міграції БД.
3. **Конфігурація** — лише через змінні оточення з `.env` (у `.gitignore`), шаблон — `.env.example`.
4. **Runner на етапі лаби №2 — `SimulatedRunner`**: виконує статичні перевірки без запуску коду. Довірений сервіс оркестрації не повинен виконувати код студентів (ADR-0001); реальний sandbox у gVisor з'явиться разом із Kubernetes.

## Наслідки

- Середовище розгортається командою `docker compose up -d --build`; БД, Redis і сховище недоступні з хоста та з інтернету.
- Перша збірка образу триває кілька хвилин (завантаження Gradle і залежностей), наступні — секунди завдяки кешу шарів і cache mount.
- RustFS — молодший проєкт за MinIO; оскільки сервіси працюють через стандартний S3 API (MinIO Java SDK), сховище можна замінити без змін у коді (у продакшені — Google Cloud Storage).
- Статичний runner не виконує тести, тому бали на цьому етапі навчальні; формат звіту вже фінальний.
